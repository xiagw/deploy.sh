## 修复约定（高危 #3/#4/#5 已用, 中危沿用）

1. 命令替换必须兜底: `var=$(cmd ...) || true` / 放进 `if !`。
2. `&&` 列表末尾加 `|| true`, 避免 errexit 豁免仅在 `||` 前失效。
3. `_msg` 无错误时一律 `>&2`（检测链 stdout 只能有业务返回值）。
4. 布尔门控判断用 `[[ ... == true ]]`, 不做字符串当命令。
5. 失败即 fail-fast: `|| { _msg error; return 1; }`, 不吞码、不后台化。
